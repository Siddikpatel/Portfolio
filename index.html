About Me

I have completed my Master’s in Applied Computer Science at Dalhousie University in Halifax, with experience across mobile development, cloud computing, and data engineering.

In my final semester, I completed a co-op term as a Junior Data Engineer, where I built Python tools to generate Oracle metadata, resolved database issues impacting dashboards, supported existing data pipelines, and developed an internal vacation entitlement calculator adopted by the People and Culture department. I also designed Power Automate workflows for automated emails and task creation.

My project work includes a React Native mobile app that identifies waste materials from images and provides disposal or recycling guidance, as well as a cloud-based web application built on AWS using a tier-3 architecture with EC2, S3, DynamoDB, API Gateway, and Lambda.

More recently, I independently developed and published an iOS app, Mood Tracker, built with React Native, TypeScript, and custom CSS, along with an iOS widget developed in Swift to help users analyze behavioral patterns over time.

I am currently seeking an entry-level opportunity where I can apply my skills in software development and cloud computing while continuing to grow professionally.
